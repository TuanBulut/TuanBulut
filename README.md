### 🚀 Flagship Project: **Barbican**
**Autonomous AI-Driven Security Orchestration, Automation & Response (SOAR) Platform.**

A next-generation security platform incorporating **DeepSeek R1** for intelligent threat analysis, **GraphRAG** for attack topology mapping, and autonomous active defense.

> **Key Features:**
> - **Autonomous Defense:** AI-driven firewall patching (IPTables) and active remediation.
> - **Graph-Based Analytics:** Real-time attack topology using **PyTorch Geometric** & **NetworkX**.
> - **Deception Engineering:** Integrated **Cowrie** honeypots with behavior profiling.
> - **Polyglot Architecture:** High-performance **Blazor Server** Dashboard backed by **FastAPI** microservices.
